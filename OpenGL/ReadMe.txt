
HOW TO RUN glfwExample.cpp (make sure your in src or you can edit it to work from buildVCPKG)
    cd buildVCPKG
    cmake ..
    cmake --build .
    src\Debug\glfwExample.exe

    WASD to move camera around

The Difference between OpenGL and Ray Tracing is that there is a lack of shadows and also the spheres colors look different. The OpenGL one looks more vibrant compared to the Ray Tracer which looks more dull
